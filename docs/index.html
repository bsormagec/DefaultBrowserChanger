First-Time macOS Gatekeeper Notice

Because DefaultBrowserChanger is free and open-source without an expensive Apple Developer ID notary subscription, macOS Gatekeeper may show a warning on first launch. Simply run this one-line command in Terminal to clear the quarantine flag:

xattr -cr /Applications/DefaultBrowserChanger.app
FAQ

Frequently Asked Questions

Got questions about how DefaultBrowserChanger works under the hood? Here are the answers.

Why do I need to set DefaultBrowserChanger as the macOS default? +
DefaultBrowserChanger acts as a high-speed (0.001s) URL proxy. By being the system default, it catches all outgoing links from apps like Slack, Mail, or WhatsApp, and instantly dispatches them to whichever browser you've currently activated in the menu bar.
Why does macOS show a Gatekeeper warning on first launch? +
DefaultBrowserChanger is a free, independent open-source project without a paid Apple Developer notary certificate. Running xattr -cr /Applications/DefaultBrowserChanger.app strips the quarantine attribute. The entire Swift source code is public on GitHub for you to audit.
Which web browsers are supported? +
All major browsers including Safari, Google Chrome, Arc, Brave, Firefox, Microsoft Edge, Opera, Orion, Zen, Vivaldi, and any browser registered as an HTTP/HTTPS handler in macOS.
Does it slow down link opening? +
Not at all. Link routing uses native macOS NSWorkspace.shared.open calls with direct bundle identifiers, taking less than 1 millisecond. You won't notice any latency compared to opening directly.
How do I uninstall DefaultBrowserChanger completely? +
Simply change your default web browser in System Settings back to Safari or Chrome, and move DefaultBrowserChanger.app from /Applications to Trash. It leaves zero daemons, background agents, or configuration files behind.
